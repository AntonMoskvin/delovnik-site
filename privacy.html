Политика конфиденциальности

Приложение «Деловник» для Android. Дата вступления в силу: 11 ноября 2026 года.

1. Общие положения

Политика описывает, какие данные обрабатывает приложение «Деловник» (далее — Приложение). Оператор: разработчик приложения «Деловник». Контакт: delovnikapp@yandex.com.

2. Данные, которые хранятся на устройстве

  • Задачи, подпункты, напоминания, категории и настройки (например, тема оформления) хранятся в локальной базе на устройстве.
  • Токен GitHub и ключ API для умного разбора, если пользователь их ввёл, хранятся локально в настройках Приложения.

Эти данные не отправляются разработчику.

3. Данные, которые передаются третьим лицам

  • Распознавание речи. Звук обрабатывается сервисом распознавания речи, установленным на устройстве (например, сервисом Google). Приложение само аудио не отправляет.
  • Умный разбор текста (LLM). Только если пользователь включил его и ввёл свой ключ API, распознанный текст задачи отправляется выбранному пользователем провайдеру. Аудио не отправляется.
  • Резервная копия в GitHub. Если пользователь ввёл токен и создал копию, файл с задачами сохраняется в его собственном приватном Gist на GitHub.
  • Резервная копия в файл. Файл сохраняется туда, куда его направит пользователь, включая облачное хранилище на его выбор.
  • Аналитика. AppMetrica собирает анонимную статистику использования и отчёты о сбоях (модель устройства, версия ОС, версия приложения, события в приложении). Сбор можно отключить в настройках: раздел «Приватность» → «Анонимная статистика».

4. Разрешения и их назначение

  • Микрофон — для голосового ввода задачи.
  • Уведомления — для показа напоминаний.
  • Точные будильники — чтобы напоминания срабатывали в назначенное время.
  • Доступ к сети — для резервных копий, аналитики и умного разбора.
  • Запуск после перезагрузки — чтобы восстановить напоминания после выключения устройства.

5. Что Приложение не делает

  • Не требует аккаунта.
  • Не продаёт данные и не передаёт их рекламным сетям.
  • Не собирает контакты, сообщения, местоположение и фотографии.

6. Хранение и удаление

  • Локальные данные удаляются вместе с удалением Приложения.
  • Резервные копии в GitHub или файле пользователь удаляет самостоятельно.
  • Данные аналитики хранятся в AppMetrica согласно политике этого сервиса.

7. Дети

Приложение не предназначено для детей.

8. Изменения политики

Актуальная версия политики всегда доступна по этому адресу.

9. Контакты

По вопросам обработки данных: delovnikapp@yandex.com.
